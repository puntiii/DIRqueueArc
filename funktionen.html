FunktionenFeatures

Alles, was Sie zum Erstellen von QR-Codes brauchen – in einer ausführbaren Datei.

Everything you need to create QR codes – in a single executable file.

Hinweis: Fiktives Produkt. Die beschriebenen Funktionen dienen nur der Übung.

Note: fictional product. The described features are for practice only.

  • Beliebig viele CodesAny number of codes

    Erstellen Sie einzelne QR-Codes oder ganze Serien – so viele, wie Sie brauchen.

    Create single QR codes or whole series – as many as you need.

  • WarteschlangeQueue

    Fügen Sie Einträge in eine Warteschlange ein. queueArc arbeitet sie der Reihe nach ab.

    Add entries to a queue. queueArc works through them one by one.

  • StapelverarbeitungBatch processing

    Laden Sie eine Liste (z. B. aus einer Textdatei) und erzeugen Sie alle Codes auf einmal.

    Load a list (e.g. from a text file) and generate all codes at once.

  • Gängige FormateCommon formats

    Exportieren Sie als PNG, SVG oder PDF – für Druck und Bildschirm.

    Export as PNG, SVG or PDF – for print and screen.

  • Farben & GrößeColors & size

    Passen Sie Farbe, Größe und Fehlerkorrektur an Ihren Einsatzzweck an.

    Adjust color, size and error correction to your purpose.

  • Offline & ohne KontoOffline & no account

    Keine Anmeldung, keine Cloud, keine Datenübertragung.

    No login, no cloud, no data transfer.
